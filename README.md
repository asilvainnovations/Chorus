# huli-ka
| Feature              | Implementation                                                             |
| -------------------- | -------------------------------------------------------------------------- |
| **Multi-Model Chat** | OpenRouter unified API (OpenAI, Anthropic, Google, xAI, DeepSeek, Mistral) |
| **Streaming**        | SSE via `fetch` with `ReadableStream`                                      |
| **RAG Search**       | Tavily/Serper API with citation injection                                  |
| **Image Generation** | DALL-E 3, Stable Diffusion XL, FLUX via OpenRouter/Replicate                                                   
| **Command Palette**  | `Ctrl+K` with keyboard navigation                                          |
| **Theme**            | System-aware dark/light mode                                               |
| **State Management** | Zustand with localStorage persistence                                      |
| **Voice Input**      | Web Speech API                                                             |
| **PDF/URL**          | Document parsing service integration                                       |
